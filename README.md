# שיבוץ גן תקשורת — מערכת תיאום טיפולים שבועית

מערכת אינטרנטית בעברית (RTL) מותאמת למחשב ולנייד (Android & iOS) לניהול ותיאום מערכת הטיפולים השבועית בגן תקשורת עבור 6 ילדים וצוות מטפלות (ענבר - פיזיותרפיה, יעל - קלינאות תקשורת, שירלי - ניתוח התנהגות, עם אפשרות להוספת מקצועות נוספים בעתיד).

## יכולות עיקריות
- **לוח שבועי מלא ורספונסיבי** + **טבלה מרוכזת** עם סינון מלא לפי מטפלת/מקצוע, ילד, סוג טיפול (פרטני 1:1 / קבוצתי), יום וסטטוס.
- **מנוע בדיקת כללים חי (ירוק / צהוב / אדום)**:
  - טיפולים באורך 45 דקות עם מרווח 15 דקות (`XX:00–XX:45`).
  - **תמיכה באזהרה צהובה לרצף כפול**: ניתן לשבץ 2 טיפולי 1:1 ברצף ללא הפסקה בסימון צהוב, עם חובת הפסקת 30 דקות לאחריהם (וכל הכללים ניתנים לעריכה בהגדרות).
  - מניעת חפיפה של מטפלות או ילדים, ומניעת שיבוץ 2 טיפולי 1:1 לאותו ילד עם אותה מטפלת באותו יום.
- **החלפה ושינוי משבצת חכם**: בלחיצה על כל טיפול, המערכת מציגה את כל המשבצות הזמינות (ירוק וצהוב) + הצעות החלפה דו-צדדיות + אפשרות לחסום שעה לא נוחה.
- **מעקב מכסות לכל ילד/ה**: הצגת השלמת המכסות (2 פרטני + 3 קבוצתי בשבוע לכל מקצוע) ואפשרות להשלמה מהירה.
- **שיתוף צוותי ללא שרת**: שמירה מקומית אוטומטית, קישור שיתוף דחוס (לוואטסאפ), ייצוא/ייבוא JSON, והדפסה/PDF.

## פיתוח מקומי

```bash
npm install
npm run dev
npm test
npm run build
```
